# Decay Sail

Diamagnetically levitated rotor driven by an under-rotor electrostatic stator, toward
measuring the alpha-recoil force from a Pb-212 source.

Start with `measurement_objective.md` (the goal), `CLAUDE.md` (how to work here, hardware
traps, where things live), and `docs/` (`DECISIONS.md` current values, `STATUS.md` open items).
